# Memory

Files below are in `~/.claude/projects/-Users-joshuacrowe/memory/`, the JoshuaBrain repo.

- **Push immediately.** After any memory edit, `git add -A && git commit && git push` in
  that directory, in the same turn. (`methodology_joshuabrain_push_policy`)
- **Rewrite a corrected fact as a clean current-state snapshot.** No "was X, corrected
  to Y on <date>" narrative; keep the constraint, drop the rejected idea.
  (`feedback_memory_editing_style`)
- **Route before writing.** CAIRN — any team. SoloCAIRN — any solo maintainer.
  JoshuaBrain — personal only. The repo's own `CONTRIBUTING.md` — binding, per-repo, and
  where conventions and standards belong. (`methodology_four_homes_framework`)
- **A feature idea goes to that repo's GitHub Ideas board as an issue**, never into a
  memory note. (`feedback_idea_routing`)
- **These rule files hold the operative line; the memory files hold the reasoning.**
  Change one, change the other.
